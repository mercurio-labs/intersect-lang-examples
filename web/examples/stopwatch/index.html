Stopwatch

An executable state machine: Rcore defines legal transitions, Xtext parses start/wait/stop commands, and Intersect Run schedules deterministic time.

Open the Stopwatch simulator →

stopwatch Demo {
  start
  wait 2s
  stop
  wait 500ms
  start
  wait 750ms
  stop
}

The watch reads 2750 ms at simulation time 3250 ms. Starting after stopping resumes the accumulated duration. Waiting while stopped advances simulation time without increasing elapsed time. Invalid transitions are recorded as rejections.

Run the commands, then play or step through the observations. Change a wait duration and run again. Timing is simulated; browser replay shows recorded results.
